# Trainer status badge sources

Created with the built-in image_gen tool, transparent_background=true. The
provided class trainer screenshot was used only as a visual style reference.
The original PNGs are kept here; only the power-of-two RGBA TGA textures in
assets/ are shipped. Alpha bounds were trimmed and images resized for game use.

## NEW +

Create a single tiny fantasy MMORPG UI status badge, transparent background, not a mockup. Wide compact rectangular dark charcoal black plaque with beveled tarnished gunmetal/bronze rim matching the classic World of Warcraft trainer panel in the reference screenshot. Bold crisp luminous emerald green exact text 'NEW +' centered, the + larger and prominent. Straight front view, flat graphic with subtle hand-painted metallic edge, minimal bevel, no extra ornaments or objects.
